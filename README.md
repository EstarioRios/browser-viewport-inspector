# Browser Viewport Inspector

A Python-based tool for controlling a Chromium browser viewport, adjusting its dimensions, and tracking mouse coordinates in real time.

## Features

- Open a website by entering its URL.
- Set custom browser viewport width and height.
- Track mouse coordinates within the page.
- Display the current viewport dimensions.
- Control the browser through a Python application.
- Built with Python and Playwright.

## Requirements

- Python 3.9+
- Playwright
- Chromium browser

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/browser-viewport-inspector.git
cd browser-viewport-inspector
```

Install the dependencies:

```bash
pip install playwright
playwright install chromium
```

## Usage

Run the application:

```bash
python live_browser_viewport.py
```

Enter the target URL, configure the desired viewport dimensions, and use the browser to inspect the page and its mouse coordinates.
